## 报告结构

48 份统一模板：`【实验目的】【实验内容】【实验记录】【问题与分析】`。

- 第一部分 = **【实验记录】**（步骤 + 截图 + 说明）
- 第二部分 = **【问题与分析】**（固定 4 题 + 表 1.1–1.4）
- 细则里写的「实验结果与分析」在报告里不存在。冲突时**以报告实际结构为准**。

## 评分细则（教师给定）

1. 实验记录空白，或写得非常简略，或只粘几张截图，或截图不清楚：**-20**
2. 问题与分析答错一题：**-3~5**；漏做一题：**-5**；最低 **70**
3. 排版整齐规范：**+5**
4. 分析详细、截图清晰、有结果标注、有自己见解：**+10**，最高 **95**

## 执行口径（本仓库）

- 基准 **85**（完整合格）；按上面扣分；排版 +5；优秀 +10；clamp **[70, 95]**
- 整批校准：统一平移（+0.5~+1.5，个别 +1），使平均 ≈ **91**，排序不变
- **不做**抄袭检测和「打回」（教师明确不做）
- 合理差异不扣：抓包帧数 8/11、脚本手写 vs 智能体、RTT 数值、拓扑描述详略、MAC/IP 不同
- 才扣：层次顺序写反、ICMP 记入应用层、TTL 与 RTT 填反、IP/MAC/命名空间张冠李戴、结论与截图矛盾
- 表 1.x 只看必填项填没填全，不要求数值唯一

## 批改意见

首页「手写签名」下方、学院名上方，红框 + 黑体（SimHei）10pt 红字：

```
批改意见
实验记录：<完整 / 偏简 / 空白 + 扣分>
问题与分析：<每题情况 + 扣分>
加分：+5（排版整齐）｜+10（分析详细、截图清晰）
最终得分：<分数>
```

框高按文本自适应，底边留 8pt 避开页脚；字号最低 8pt。

## 输出

- 首页右上「分数」填分数、「教师签名」填 **徐海燕**（红字）
- 文件名：`<原文件名>_批改.pdf`；原件只读，产物放 `实验<N>批改\`
- 成绩单：`学号 / 姓名 / 实验一 … 实验六 / 平均分`；一学期共 **6 个实验**，平均分 `AVERAGE(C:H)`

## 校验

```
python scripts/verify_batch.py --submitted <提交目录> --graded <批改目录> --xlsx <成绩单> --experiment 1 --target-mean 91
```

检查内容：每份提交都有批改副本；首页含「批改意见 / 最终得分 / 徐海燕」；分数在 [70, 95]；成绩单对应列每个已交学生都有分且与 PDF 一致；平均分在目标 ±0.5。任一失败即非零退出。
